# MVP: оценка взаимодействия между подразделениями

Готовое веб-приложение на Next.js, PostgreSQL, Prisma и Tailwind CSS для ежемесячной оценки взаимодействия между подразделениями компании.

## Что реализовано

- Авторизация с ролями: администратор, руководитель подразделения, просмотр / аналитика.
- Справочники подразделений, руководителей, периодов и критериев.
- Форма оценки по шкале 1-10.
- Обязательный комментарий для оценок ниже 9.
- Автоматический расчет средних баллов, количества оценок ниже 9 и отсутствующих оценок.
- Дашборд с цветовой индикацией: 9-10 зеленый, 8-8.99 желтый, ниже 8 красный.
- Блок проблемных зон с комментариями.
- Рейтинг подразделений.
- Heatmap-матрица взаимодействия с просмотром комментария по клику.
- Контроль заполнения по каждому оценивающему подразделению.
- Админ-панель: подразделения, критерии, руководители, открытие и закрытие периода, просмотр комментариев.
- Экспорт результатов в `.xlsx`.
- Seed-данные для демонстрации.

## Оптимальный стек

- Next.js App Router: быстрый MVP и удобное дальнейшее расширение.
- PostgreSQL: надежное хранение и простая серверная эксплуатация.
- Prisma: понятная схема, миграции, seed-данные, Prisma Studio для администрирования.
- Tailwind CSS: быстрый корпоративный интерфейс без тяжелой дизайн-системы.
- XLSX: экспорт Excel без отдельного сервиса.

Этот стек проще поддерживать, чем самописные Excel-процессы, и гибче, чем Google Apps Script, если дальше нужны роли, уведомления, KPI, PDF-отчеты и интеграции.

## Запуск локально

1. Установите зависимости:

```bash
npm install
```

2. Создайте `.env` из примера:

```bash
cp .env.example .env
```

На Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

3. Запустите PostgreSQL:

```bash
docker compose up -d
```

4. Создайте таблицы и наполните демо-данными:

```bash
npm run db:push
npm run prisma:seed
```

5. Запустите приложение:

```bash
npm run dev
```

Откройте `http://localhost:3000`.

## Основные экраны

- `/dashboard` - сводный дашборд, рейтинг, проблемные зоны, динамика.
- `/matrix` - heatmap-матрица оценок между подразделениями.
- `/evaluations` - форма заполнения оценки и последние оценки периода.
- `/completion` - контроль заполнения.
- `/admin` - справочники, периоды, руководители, комментарии и экспорт.

## Структура проекта

```text
app/                  Страницы и API routes Next.js
components/           UI-компоненты
lib/                  Авторизация, Prisma, расчеты, форматирование
prisma/schema.prisma  Модель данных
prisma/seed.ts        Демо-данные
docker-compose.yml    PostgreSQL для локального запуска
```

## Развертывание

Подойдет любой сервер или PaaS, где можно запустить Next.js и PostgreSQL:

- VPS с Node.js, PostgreSQL и `npm run build && npm run start`.
- Docker / Docker Compose.
- Render, Railway, Fly.io, Heroku-подобные платформы.
- Vercel для Next.js плюс внешний PostgreSQL.

Для production обязательно задайте надежный `AUTH_SECRET` и production `DATABASE_URL`.
