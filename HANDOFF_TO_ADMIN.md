# Передача системному администратору

Нужно разместить веб-приложение оценки взаимодействия подразделений на виртуальном сервере.

## Что передать

Передайте всю папку проекта:

```text
mvp-next-js-postgresql-prisma-tailwind
```

И попросите администратора начать с файла:

```text
DEPLOYMENT_FOR_ADMIN.md
```

## Что это за приложение

Корпоративный MVP для ежемесячной оценки взаимодействия между подразделениями.

Основные функции:

- роли: администратор, руководитель, просмотр;
- справочники подразделений, руководителей, периодов и критериев;
- обязательные пары оценивания;
- массовое назначение отделов, которые должны оценить все остальные;
- форма оценки 1-10;
- обязательный комментарий при оценке ниже 9;
- кнопка «Нет взаимодействия»;
- дашборд;
- матрица взаимодействия;
- контроль заполнения;
- экспорт в Excel.

## Что нужно от администратора

1. Выделить виртуальный сервер.
2. Подготовить домен или поддомен, например:

```text
hr.redpetroleum.kg
```

3. Установить:

```text
Node.js LTS
PostgreSQL
Nginx
Certbot
```

4. Создать базу PostgreSQL.
5. Настроить `.env`.
6. Выполнить команды Prisma.
7. Собрать приложение.
8. Запустить через systemd.
9. Настроить Nginx и HTTPS.
10. Настроить бэкапы PostgreSQL.

Полные команды находятся в:

```text
DEPLOYMENT_FOR_ADMIN.md
```

## Важные параметры

Внешний URL после размещения:

```text
https://hr.redpetroleum.kg
```

Ссылка для руководителей:

```text
https://hr.redpetroleum.kg/evaluations
```

Ссылка для администратора:

```text
https://hr.redpetroleum.kg/admin
```

## Что заменить перед production

- `DATABASE_URL`
- `AUTH_SECRET`
- `APP_URL=https://hr.redpetroleum.kg`
- SMTP-параметры для отправки писем руководителям
- `CRON_SECRET` для автоматической обработки просроченных оценок
- домен в Nginx
- демо-пользователей
- демо-пароли
- список подразделений
- список руководителей
