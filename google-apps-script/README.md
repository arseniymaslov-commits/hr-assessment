# Google Apps Script MVP

Это упрощенная Google-версия системы оценки взаимодействия: Google Sheets хранит данные, Apps Script показывает web-интерфейс по ссылке.

## Что умеет

- Справочники подразделений, руководителей, периодов и критериев.
- Роли: администратор, руководитель, просмотр.
- Форма оценки 1-10.
- Правило: если оценка ниже 9, комментарий обязателен.
- Дашборд со средними баллами, рейтингом и проблемными зонами.
- Матрица взаимодействия.
- Контроль заполнения.
- Админ-панель.
- Лист «Экспорт» для выгрузки данных из Google Sheets.

## Как развернуть

1. Создайте новый Google Sheet.
2. Откройте `Расширения -> Apps Script`.
3. Вставьте содержимое `Code.gs` в файл `Code.gs`.
4. Создайте HTML-файл `Index` и вставьте содержимое `Index.html`.
5. Сохраните проект.
6. В Apps Script выберите функцию `setupMvp` и нажмите `Run`.
7. Разрешите доступ к таблице.
8. Нажмите `Deploy -> New deployment`.
9. Тип deployment: `Web app`.
10. Execute as: лучше `User accessing the web app`, если у вас Google Workspace.
11. Who has access: `Anyone within your organization` или нужный вариант доступа.
12. Нажмите `Deploy` и скопируйте Web App URL.

Эту ссылку можно отправлять оценивающим.

## Важное про авторизацию

В Google Workspace Apps Script обычно может получить email пользователя через Google-аккаунт. Тогда роль определяется по листу «Пользователи».

Если email не передался автоматически, веб-форма покажет поле ручного входа по email. Для пилота это удобно, но для production лучше использовать Google Workspace-доступ внутри организации.

## Демо-пользователи

После `setupMvp` создаются тестовые пользователи:

| Роль | Email |
| --- | --- |
| Администратор | `admin@company.test` |
| Просмотр | `viewer@company.test` |
| Руководитель продаж | `anna@company.test` |
| Руководитель IT | `roman@company.test` |

В Google-версии пароль не используется: доступ контролируется Google-аккаунтом или ручным email для пилота.

## Как затем масштабировать

Когда процесс подтвердится на Google Sheets:

- переносим модель данных в PostgreSQL;
- сохраняем UX и правила проверки;
- добавляем нормальную авторизацию;
- разворачиваем Next.js-версию на сервере;
- добавляем email / Telegram-уведомления, KPI и PDF-отчеты.
