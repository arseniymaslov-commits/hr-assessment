# Бэкап и восстановление базы

Перед массовыми изменениями, переносом оценок или обновлением структуры базы сделайте резервную копию.

## Создать бэкап

1. Установите PostgreSQL client tools, чтобы были доступны `pg_dump` и `pg_restore`.
2. В терминале задайте `DATABASE_URL` от Neon.
3. Запустите:

```powershell
npm run db:backup
```

Файл появится в папке `backups` в формате `hr-assessment-YYYYMMDD-HHMMSS.dump`.

## Восстановить базу

Восстановление перезаписывает текущие данные в базе. Перед этим лучше сделать еще один свежий бэкап.

```powershell
npm run db:restore -- .\backups\hr-assessment-YYYYMMDD-HHMMSS.dump
```

## Рекомендованный порядок перед релизом

1. Сделать бэкап базы.
2. Запустить `npm test`.
3. Запустить `npm run build`.
4. После деплоя проверить вход, дашборд, оценку и экспорт Excel.
